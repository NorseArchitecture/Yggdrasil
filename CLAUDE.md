## What This Realm Is

Yggdrasil is **connective tissue** — `Norse.Hosting`: the web, worker, and migration service chassis and the deployables built on it. It hosts the runtime endpoints Bifröst composes but never provides itself — every service, component, and contract it serves is declared in another realm and lands here by reference. It rides on Midgard and everything below; nothing rides on Yggdrasil. The README's chart draws every edge; transitive-first holds throughout.

## Build & Test

- `dotnet build Yggdrasil.slnx` — warnings are errors; a single warning fails.
- `dotnet test Yggdrasil.slnx` — xUnit v3 + Shouldly on Microsoft.Testing.Platform. **VSTest `--filter` does NOT work** — use `dotnet test tests/<Project> -- --filter-class "*.<ClassName>"`. `CountryLookupE2ETests` needs Docker (Testcontainers Postgres).
- **`CompositionTests` boot the real `Program.cs`** via `WebApplicationFactory<Program>`. Connection strings must be set as process env vars in a static constructor — `Program.cs` reads them before `builder.Build()`, earlier than any `WithWebHostBuilder` hook applies; env vars are the one override its pre-Build read can see. Nothing in these tests opens a connection.
- **`WireModelFixture` is an `[assembly: AssemblyFixture]`** warming `RuntimeTypeModel.Default` once, before any test. Never re-register surrogates per fixture — that is the registration-vs-registration TOCTOU this design removed.
- **`SwoopHostFixture`/`WiringTests` are the live "wired, not just designed" probes** — tri-protocol host over the test-local `ParityController`, hand-registered exactly as the generators would emit. The negotiation-law pins live there: no-Accept defaults to JSON, unmatched Accept gets 406. Removing a registration from the fixture must fail the suite.
- **bUnit + FluentUI v5 rc5**: components read `RendererInfo`, so setup must call `Renderer.SetRendererInfo(...)` — and touching `Renderer` seals bUnit's service collection, so it must be the LAST line of setup.
- SDK auto-resolves, never pins: `global.json` floats on `11.0.100-` with `rollForward: latestFeature` + `allowPrerelease` — a new .NET 11 preview is picked up on drop day with no file edit (the toolchain's auto-resolving-over-pinned doctrine).
- **Yggdrasil is the platform's one CPM realm** — the composition root owns and pins the deployed dependency closure (`Directory.Packages.props`, one `{Realm}Version` property per realm). Inside Bifröst the `NorseRef` workspace crossing forwards to local realm projects, so realm changes are visible before any tag; standalone CI rides the package crossing and needs the train order (upstream realm tags first, then the CPM bumps here). Doctrine: `../Glitnir/docs/the-runes.md` — read it before touching any `Directory.Build.*` file.
- **`Hosting.Stories` dev loop**: `ASPNETCORE_ENVIRONMENT=Development` is required for `dotnet run` to serve static web assets at all (dev-only wiring, unless the app is actually published) — a bare `dotnet run` with no environment set 404s/500s on everything. (The old Stories host's WASM-boot SRI-caching foot-gun is retired along with the WASM loader itself — `../Glitnir/docs/Platform/specs/2026-08-22-stories-blazor-server-mcp-design.md` §9.)

## Architecture Facts (decided — do not re-litigate)

- **The mediator pipeline composes in DI; the gateway machinery is retired** (`../Glitnir/docs/Platform/specs/2026-07-27-mediator-pipeline-retires-gateway-design.md`). Components inject `I{Context}Service` directly — no gateway interface exists between component and service.
- **Principal seeding is per-channel, one accessor** (spec §2.4): Midgard's `PrincipalSeedingInterceptor` seeds the gRPC channel, `PrincipalSeedingFilter` (registered by `AddNorsePipeline()`) seeds the MVC/REST channel, and a circuit scope defers live to `AuthenticationStateProvider`. The REST filter exists because the fallback throws outside a circuit — found live on this composition root 2026-08-10; every test fixture had masked it by overriding `IPrincipalAccessor`.
- **Negotiation is honest, and formatter order is the default-channel law.** `AddControllers(options => options.ReturnHttpNotAcceptable = true)` — an Accept naming neither JSON nor XML gets a 406, never the first formatter's best guess. JSON is the no-Accept default because System.Text.Json is registered first (`AddNorseXml` appends, never front-inserts); XML is opt-in by Accept header. Facades carry no Swashbuckle-era `[Consumes]`/`[Produces]` — Asgard law: `ConsumesAttribute` doubles as `IAcceptsMetadata` and made every bodyless GET unroutable via the Content-Type DFA partition.
- **The OpenAPI document declares exactly what the REST leg serves.** Midgard's four transformers (Result/Enum/XmlMetadata/UnionLeakGuard) plus the host's `StandardResponsesTransformer`: the standard idiomatic response codes on every operation, the `Problem` component (RFC 9457 + the `errors` array), and success-content normalization to the two real channels — ApiExplorer's formatter-union noise (`text/plain` first) sent Scalar's try-it default straight into a 406 the document had promised wouldn't happen. The document carries only the reference facade; every other mapped endpoint carries `ExcludeFromDescription()` at its own map site. Scalar (`/scalar/v1`) and gRPC reflection are dev-only discovery surfaces; both integrate with Postman/Bruno (see Vafthrudnir).
- **Policy names are registered here, never declared here.** Realms name policies (`ReferencePolicies.Public`, `AuthNPolicies.Public`, `IdentityPolicies.*`); the composition root registers what satisfies them.
- **ServiceDefaults lives in Midgard** (ruled 2026-06-28) — never here, never Bifröst, Aspire convention notwithstanding.
- **The identity page tree lives upstream.** Login/Register/Logout are Heimdall's, the account/manage/passkey tree is Himinbjörg's `Identity.Web.Server`; this repo registers and maps them — `Hosting.Web.Server/Components/` holds only `App.razor`, `_Imports`, `ReconnectModal`, and `Error`.
- **Every deployable follows spec-first**: brainstorm → spec → plan in `../Glitnir/docs/Yggdrasil/`, human greenlight at each transition. Implementation is subagent-orchestrated and test-driven (`superpowers:subagent-driven-development` + `superpowers:test-driven-development`; full rule `../Glitnir/CLAUDE.md` §2.8).

See `../Bifrost/CLAUDE.md` (§2 The Naming Model) and `../Glitnir/CLAUDE.md` (§3 Bounded Context Map) for the full realm table and how Yggdrasil fits the cosmos.
